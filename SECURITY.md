# Security Policy

## Supported versions

Security fixes are applied to the latest commit on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details, credentials, personal data, or production configuration.

Include the affected component, reproduction steps, impact, and any suggested mitigation. Maintainers should acknowledge a complete report within seven days and coordinate disclosure after a fix is available.

## Operational scope

PRANA is research and decision-support software. Its legal documents and dispatch records are drafts or internal queue records unless an authorized external provider is explicitly integrated. Do not treat model estimates as regulatory measurements or medical advice.
